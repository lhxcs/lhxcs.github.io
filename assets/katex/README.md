KaTeX 0.16.22
=============

Vendored from the official `katex@0.16.22` npm package (https://katex.org/).
MIT license; see LICENSE.

Contains the minified renderer, auto-render extension, CSS, and WOFF2 fonts.
The CSS omits the legacy WOFF/TTF fallbacks; all bundled fonts use WOFF2.
Hosting these assets locally keeps article formulas independent of a CDN.
